# START HERE — Camila Online

Este archivo es el punto de entrada canónico para cualquier chat nuevo que trabaje sobre este proyecto.

## Fuente de verdad

El repositorio `JonatanGarbuyo/camila-online` es la fuente de verdad y base de conocimiento durable del proyecto.

## Bootstrap obligatorio

Antes de avanzar:

1. Leer `README.md`.
2. Leer `PROJECT-RULES.md`.
3. Leer `CONTEXT.md`.
4. Leer `docs/wayfinder/map.md`.
5. Revisar los Issues Wayfinder abiertos relevantes y sus comentarios.
6. Cargar las skills necesarias desde `mattpocock/skills`.
7. Reconstruir el estado actual desde el repo antes de proponer trabajo nuevo.

## Wiki para operadores

`wiki/README.md` es la entrada a la guía práctica para Camila y otros operadores no técnicos.

No usar `/wiki/` para Wayfinder, Issues, research ni comparaciones internas. Solo debe contener procedimientos operativos claros.

## Persistencia

Al terminar trabajo significativo, guardar solamente conocimiento durable: investigación verificada, restricciones, decisiones, riesgos, cambios de Wayfinder, preguntas abiertas y procedimientos operativos.

Los procedimientos operativos nuevos o actualizados deben vivir en `wiki/`.

## Autoridad

- Las decisiones finales requieren aprobación explícita de `@JonatanGarbuyo`.
- Otros usuarios pueden investigar, debatir y proponer.
- `@JonatanGarbuyo` es quien realiza desarrollo y ejecución de código.

## Seguridad

Nunca guardar contraseñas, tokens, API keys, secretos, credenciales ni datos privados de clientes en el repo.

Si una persona no técnica va a realizar una acción riesgosa, costosa o difícil de revertir, explicar antes el riesgo y la alternativa segura.
