# Pedir ayuda al chat

[← Volver al índice de la wiki](README.md)

El chat de este proyecto es el **canal oficial de ayuda operativa** para Camila y otros operadores de la tienda.

Se puede usar cuando haya dudas sobre qué hacer, cómo seguir un procedimiento o cómo resolver un problema durante la administración de la tienda.

El chat debe apoyarse primero en esta wiki y en la documentación durable del proyecto. Si la respuesta depende de una función actual de Tiendanube, DonWeb, Empretienda u otro proveedor, debe verificar la documentación vigente antes de indicar pasos.

## Qué tipo de ayuda pedir

Por ejemplo:

- “No sé cómo cargar un producto con varios talles.”
- “El stock que veo en la tienda no coincide con el local.”
- “Tengo un pedido pagado. ¿Qué hago ahora?”
- “No encuentro dónde generar la etiqueta del envío.”
- “Necesito cancelar una venta y devolver el dinero.”
- “Este producto no aparece en Google.”
- “Quiero publicar esta prenda en Instagram. ¿Qué debería revisar antes?”
- “Me llegó este mensaje/error. ¿Qué significa y qué hago?”

## Cómo explicar el problema

No hace falta usar términos técnicos. Contar:

1. qué estabas intentando hacer;
2. qué esperabas que ocurriera;
3. qué ocurrió realmente;
4. en qué pantalla o servicio estás;
5. si aparece un mensaje de error, copiar el texto exacto o compartir una captura de pantalla cuando sea posible.

Si es un pedido concreto, se puede describir su estado, pero **no pegar datos privados del cliente** innecesariamente.

## Qué debe hacer el chat

El asistente debe:

1. entender primero el problema real;
2. buscar el procedimiento correspondiente en `/wiki/`;
3. dar instrucciones paso a paso y en lenguaje simple;
4. indicar cómo comprobar que el problema quedó resuelto;
5. advertir antes de cualquier acción que pueda generar cobros, pérdida de información, exposición de datos o cambios difíciles de revertir;
6. consultar documentación vigente del proveedor si la función puede haber cambiado;
7. evitar pedir contraseñas, códigos de acceso, tokens, datos de tarjetas u otras credenciales;
8. si descubre una solución reusable que no estaba documentada, dejarla preparada para incorporar luego a esta wiki.

## Cuándo no avanzar sin consultar

Detenerse y pedir ayuda antes de continuar si una acción implica:

- cobrar o devolver dinero y no está claro el procedimiento;
- eliminar productos, pedidos o información importante de forma irreversible;
- cambiar titularidad, accesos o datos fiscales;
- conectar o desconectar una cuenta de pagos;
- contratar un plan pago o una aplicación con costo;
- publicar datos privados;
- compartir una contraseña o código de acceso;
- realizar un cambio que pueda afectar muchos productos o pedidos a la vez.

## Cuándo escalar a Jonatan

El chat debe derivar a Jonatan cuando el problema requiera:

- desarrollo de software o código;
- una integración técnica no soportada de forma estándar;
- automatizaciones nuevas;
- una decisión final de arquitectura o plataforma;
- aceptar un costo importante o difícil de revertir;
- una decisión que cambie las reglas generales del servicio.

Camila puede describir el problema y proponer opciones, pero la decisión final de esos puntos queda en manos de Jonatan.

## Cuándo usar el soporte del proveedor

El chat puede ayudar a diagnosticar y preparar la consulta, pero conviene usar el soporte oficial de la plataforma o servicio cuando exista:

- bloqueo o suspensión de cuenta;
- pago retenido o movimiento de dinero que el panel no permite resolver;
- error interno o caída del servicio;
- problema de acceso que requiere verificar identidad;
- envío perdido o incidencia que solo puede resolver la empresa logística;
- comportamiento de la plataforma que contradice su documentación y no puede reproducirse o corregirse desde la configuración.

El chat puede ayudar a redactar qué información enviar al soporte y a interpretar la respuesta.

## Regla de seguridad

Nunca enviar por chat ni guardar en el repo:

- contraseñas;
- códigos de verificación;
- tokens o API keys;
- datos completos de tarjetas;
- credenciales de pagos, correo o redes sociales;
- documentos personales o información privada de clientes que no sea necesaria.

Si una captura muestra información sensible, ocultarla antes de compartirla cuando sea posible.

## Mejorar la wiki con problemas reales

Si una duda aparece más de una vez o su solución puede servir para otra tienda, debe convertirse en un procedimiento o sección de preguntas frecuentes dentro de `/wiki/`.

La idea es que cada problema resuelto haga más fácil resolver el siguiente.
