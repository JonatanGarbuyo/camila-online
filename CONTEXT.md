# Camila Online

Contexto de negocio para habilitar un nuevo canal de venta online para un comercio existente. El primer caso es una tienda de ropa, pero el aprendizaje debe distinguir entre decisiones específicas de indumentaria y un playbook reutilizable para otros comercios.

## Language

**Tienda online**:
Canal digital donde el cliente puede descubrir productos, armar una compra y completar un pedido.
_Avoid_: página web, catálogo web

**Pedido**:
Intención de compra confirmada por el cliente con productos, cantidades, datos de contacto y modalidad de entrega.
_Avoid_: consulta, carrito

**Venta asistida**:
Venta cuyo cierre requiere intervención humana por WhatsApp u otro canal.
_Avoid_: venta manual

**Venta autoservicio**:
Venta que el cliente puede completar sin intervención humana desde catálogo hasta pago.
_Avoid_: venta automática

**Costo fijo de plataforma**:
Importe recurrente necesario para mantener habilitada la tienda, sin contar comisiones por cobro, envío ni impuestos.
_Avoid_: costo total

**Costo variable por venta**:
Costo que aparece al concretar una operación, incluyendo comisión del procesador de pago y cargos de plataforma aplicables.
_Avoid_: comisión, fee

**Atribución**:
Relación medible entre una visita o venta y el enlace, campaña, publicación o referido que originó el tráfico.
_Avoid_: métricas

**Cobertura logística**:
Alcance geográfico y condiciones bajo las cuales un operador acepta y entrega un envío.
_Avoid_: envío nacional

**Seguro de envío**:
Cobertura económica adicional frente a determinados siniestros del transporte, distinta de la responsabilidad postal o legal básica.
_Avoid_: garantía

**Playbook de comercio**:
Conjunto reutilizable de decisiones, configuración y operación para habilitar una tienda online sin desarrollar software propio.
_Avoid_: plataforma, SaaS
