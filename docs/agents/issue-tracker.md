# Issue tracker: GitHub

Issues and decision tickets for this repo live in GitHub Issues.

## Wayfinding operations

- **Map:** issue labelled `wayfinder:map`.
- **Decision tickets:** issues labelled `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling` or `wayfinder:task`.
- **Child relationship:** use native GitHub sub-issues when available. Fallback used in this repo: `Part of #<map>` at the top of the ticket body.
- **Blocking:** use native issue dependencies when available. Fallback used in this repo: `Blocked by: #<n>, #<n>` at the top of the ticket body.
- **Claim:** assign the ticket before resolving it.
- **Resolve:** post the answer as a resolution comment, close the issue, and append a one-line gist + link to the map's `Decisions so far`.
- **Frontier:** open, unassigned tickets whose blockers are all closed.

## Planning rule

Wayfinder plans; it does not implement the destination. This project additionally sets **no-code** as a standing constraint for the MVP. Implementation/code tickets should not be created unless the destination is explicitly redrawn.
