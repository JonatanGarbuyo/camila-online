# Bootstrap para un chat nuevo

Usar este procedimiento cuando una conversación nueva vaya a trabajar sobre Camila Online.

## Instrucción inicial sugerida

> Trabajá sobre el repositorio `JonatanGarbuyo/camila-online` como base de conocimiento del proyecto.
>
> Antes de proponer o modificar nada:
> 1. leé `README.md`, `PROJECT-RULES.md`, `CONTEXT.md` y `docs/wayfinder/map.md`;
> 2. revisá los issues Wayfinder abiertos relevantes;
> 3. cargá desde `mattpocock/skills` las skills necesarias para esta tarea. Para discovery grande, empezá por `wayfinder`, `grilling`, `domain-modeling` y agregá `research`/`prototype` según corresponda;
> 4. no guardes secretos ni datos sensibles en el repo;
> 5. si hablás con una persona no técnica, explicá riesgos importantes en lenguaje simple antes de una acción insegura o irreversible;
> 6. no marques decisiones finales como aprobadas sin confirmación explícita de `@JonatanGarbuyo`;
> 7. si sos un participante no técnico, no ejecutes código ni hagas desarrollo: documentá la necesidad y dejala para `@JonatanGarbuyo`.
>
> Al terminar, persistí en el repo solo el conocimiento durable: hallazgos, decisiones propuestas/aprobadas, restricciones, riesgos y próximos puntos de decisión.

## Resultado esperado

Un chat nuevo debe poder continuar el trabajo leyendo el repositorio, sin necesitar el historial de conversaciones anteriores.
