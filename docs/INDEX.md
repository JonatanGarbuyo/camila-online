# Guía práctica — Tienda online

Esta es la **portada de la guía para Camila y otros operadores no técnicos**.

Acá solo debe haber conocimiento práctico: qué hacer, cómo hacerlo y cómo verificar que quedó bien.

No se documentan en esta guía decisiones internas del proyecto, Issues, Wayfinder ni investigación comparativa de plataformas.

### Disponible

- ✅ [Publicar productos y contenido + SEO](playbook/04-seo-y-publicacion.md)

A medida que cada procedimiento esté listo, se agregará acá su enlace.

## Regla para publicar

Antes de publicar un producto, usar siempre la guía de [SEO y publicación](playbook/04-seo-y-publicacion.md).

Como mínimo revisar:

- nombre entendible del producto;
- descripción original y completa;
- talles, colores y stock correctos;
- fotos claras;
- precio correcto;
- categoría correcta;
- título y descripción para buscadores;
- URL clara cuando se pueda editar;
- peso y dimensiones necesarios para envío;
- links comerciales con atribución cuando correspondan.

## Seguridad

- No compartir contraseñas por chat.
- No guardar tokens, claves, datos de tarjeta ni credenciales en esta documentación.
- Cada persona debe usar su propio acceso cuando la plataforma lo permita.
- Si una acción puede generar un costo o afectar ventas reales, confirmar antes de ejecutarla.

## Cómo mantener esta guía

- Escribir en español simple.
- Explicar pasos concretos, no conceptos técnicos innecesarios.
- Incluir siempre cómo comprobar que el paso quedó bien.
- No duplicar procedimientos: enlazar al documento correspondiente.
- Cuando se agregue un procedimiento nuevo, agregarlo también a este índice.
