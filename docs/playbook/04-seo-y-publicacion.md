# SEO y procedimiento de publicación

_Estado: base reusable. Adaptar los nombres exactos de pantallas cuando se apruebe la plataforma en #9._

Este procedimiento está pensado para una persona no técnica que administra catálogo y contenido. El objetivo no es “hacer SEO avanzado”, sino publicar cada producto y contenido con un estándar consistente, medible y fácil de revisar.

## Principio

La plataforma resuelve parte del SEO técnico. La persona que administra la tienda resuelve la calidad comercial del contenido.

Una publicación buena debe:

1. ser clara para una persona que quiere comprar;
2. describir el producto con palabras que la gente realmente usa al buscar;
3. tener imágenes suficientes y útiles;
4. permitir elegir correctamente variantes/talles/colores;
5. tener precio y stock correctos;
6. incluir datos SEO básicos;
7. publicarse con links atribuibles cuando se promociona fuera de la tienda.

## Antes de crear el producto

Reunir:

- nombre comercial del producto;
- categoría;
- precio;
- variantes: talle, color u otras;
- stock disponible por variante;
- material/composición;
- calce o características relevantes;
- medidas o guía de talles cuando corresponda;
- instrucciones de cuidado;
- al menos una buena foto y, preferentemente, varias vistas;
- información de cambio/devolución que aplique al producto.

No publicar productos con datos “a confirmar”.

## Nombre del producto

Usar un nombre que un comprador pueda entender y buscar.

Preferir:

`Remera oversize de algodón negra`

Evitar como título público:

`ART 3241`

El SKU o código interno puede guardarse en el campo correspondiente, pero no debe reemplazar el nombre descriptivo.

### Regla práctica

El nombre debe combinar, cuando tenga sentido:

`tipo de producto + característica principal + material/color/modelo`

No rellenar el título con palabras repetidas solo para intentar posicionar en Google.

## Descripción

La descripción debe ser original y responder rápidamente las dudas de compra.

Orden recomendado:

1. una frase corta explicando qué es;
2. características principales;
3. material/composición;
4. calce;
5. talles y medidas;
6. colores/variantes;
7. cuidados;
8. cualquier aclaración importante para evitar devoluciones.

Para indumentaria, la guía de talles debe existir también como texto legible siempre que sea posible; no depender exclusivamente de una imagen.

## Fotos

Antes de publicar, verificar:

- foto principal clara y bien iluminada;
- producto visible sin elementos que confundan;
- proporción y estilo consistentes entre productos;
- vistas adicionales cuando agreguen información;
- color razonablemente fiel;
- imágenes suficientemente nítidas sin archivos innecesariamente pesados.

Si la plataforma permite texto alternativo (`alt`), describir brevemente lo que muestra la imagen, por ejemplo:

`Remera oversize negra de algodón - vista frontal`

No usar listas de palabras clave en el alt text.

## Categorías

Las categorías deben ayudar tanto a comprar como a buscar.

Ejemplos:

- Remeras
- Pantalones
- Buzos
- Vestidos

Evitar categorías ambiguas como `Varios`, salvo necesidad real.

Mantener una estructura simple. No crear categorías nuevas por pequeñas diferencias que pueden resolverse con filtros o variantes.

## SEO básico de cada producto

Cuando la plataforma exponga estos campos, revisar:

### SEO title / título para buscadores

- describir el producto;
- incluir la marca si aporta valor;
- evitar títulos duplicados;
- escribir para humanos, no para algoritmos.

Ejemplo:

`Remera oversize negra de algodón | Marca`

### Meta description

Una frase breve que explique el producto y motive el clic. No repetir una lista de keywords.

Ejemplo:

`Remera oversize de algodón, disponible en varios talles. Consultá medidas, colores, medios de pago y envíos.`

### URL / slug

Preferir una URL corta y descriptiva:

`/productos/remera-oversize-negra`

Evitar códigos incomprensibles si la plataforma permite editarla.

Si una URL ya está publicada y posicionada, no cambiarla por motivos estéticos sin evaluar redirección/impacto.

## Contenido institucional mínimo

La tienda debería tener páginas claras para:

- quiénes somos;
- cómo comprar;
- medios de pago;
- envíos;
- cambios y devoluciones;
- preguntas frecuentes;
- contacto/WhatsApp.

Estas páginas mejoran confianza, reducen consultas repetidas y también aportan contexto a buscadores.

## Search Console y sitemap

Luego del lanzamiento:

1. verificar la propiedad del dominio/subdominio cuando el proveedor lo permita;
2. registrar el sitemap generado por la plataforma en Google Search Console;
3. comprobar que las páginas principales puedan indexarse;
4. revisar periódicamente errores de indexación.

No esperar resultados SEO inmediatos: Google puede demorar en rastrear e indexar contenido nuevo o actualizado.

## Publicar el producto

Antes de presionar Publicar, revisar este checklist:

- [ ] nombre claro y descriptivo;
- [ ] categoría correcta;
- [ ] descripción completa y original;
- [ ] precio confirmado;
- [ ] variantes correctas;
- [ ] stock confirmado;
- [ ] fotos revisadas;
- [ ] guía de talles/medidas si aplica;
- [ ] SEO title revisado si existe;
- [ ] meta description revisada si existe;
- [ ] URL legible si es editable;
- [ ] información de cambios/devoluciones accesible;
- [ ] vista móvil revisada;
- [ ] botón de compra funciona.

## Promocionar la publicación

No compartir directamente una URL comercial sin atribución cuando sea posible.

Usar UTMs siguiendo `docs/research/measurement.md`.

Ejemplos:

- bio de Instagram: `utm_source=instagram&utm_medium=organic_social&utm_campaign=<campaña>&utm_content=bio`
- story: `utm_source=instagram&utm_medium=organic_social&utm_campaign=<campaña>&utm_content=story_<producto>`
- publicación de Facebook: `utm_source=facebook&utm_medium=organic_social&utm_campaign=<campaña>&utm_content=post_<producto>`
- referido: `utm_source=referral&utm_medium=referral&utm_campaign=<campaña>&utm_content=<referidor>`

## Recomendación para redes

Una publicación comercial debería tener:

- una sola idea principal;
- foto/video que permita entender el producto rápido;
- nombre del producto;
- beneficio o característica concreta;
- precio cuando la estrategia comercial lo permita;
- talles/variantes relevantes;
- llamado a la acción claro;
- link atribuible a la tienda cuando el formato permita link.

No convertir WhatsApp en el checkout por defecto. Usarlo para dudas, asistencia y ventas que realmente requieran intervención humana.

## Después de publicar

Comprobar:

- que la ficha abre sin error;
- que el precio y stock coinciden con la realidad;
- que las variantes pueden seleccionarse;
- que agregar al carrito funciona;
- que la ficha se ve correctamente en celular;
- que el link promocional conserva sus UTM;
- que la visita aparece en analytics cuando corresponda.

## Revisión periódica

Semanalmente revisar:

- productos sin stock que siguen publicados incorrectamente;
- precios desactualizados;
- productos con pocas visitas;
- búsquedas/consultas frecuentes que indiquen información faltante;
- fichas con muchas visitas y poca conversión;
- enlaces rotos;
- páginas reportadas en Search Console.

## Portabilidad del procedimiento

Este procedimiento es deliberadamente independiente de Tiendanube, DonWeb, Empretienda, Wix o Shopify. Una vez aprobada la plataforma, agregar capturas/rutas de menú específicas sin cambiar las reglas editoriales de fondo.
